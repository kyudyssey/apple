# 🍎 사과게임

> 이 README는 게임을 완성한 뒤 작성합니다. 자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.

## 게임 소개

드래그하여 선택한 숫자들의 합이 **10의 배수(10, 20, 30...)**가 되도록 만드는 퍼즐 게임입니다.
- **제한시간 1분(60초)** 동안 최대한 많은 10의 배수를 조합하여 높은 점수를 획득해 보세요.
- 숫자를 지울 때마다 새 숫자가 채워지며, 최고 점수는 브라우저에 자동 저장됩니다.

## 어떻게 만들었나요

1. **GitHub Copilot Agent Mode**를 활용하여 프롬프트 기반으로 게임의 기본 구조(HTML/CSS/JS)를 단일 파일(`index.html`)에 대화형으로 구현했습니다.
2. 실행 및 테스트를 거치며 기본 10 합산 규칙을 **10의 배수 합산 규칙**으로 고치고, 제한시간 및 UI 하이라이트 동작을 대화로 수정 및 보완했습니다.
3. `dev` 브랜치에서 개발 후 `gh-pages` 브랜치를 생성하여 **GitHub Pages**로 웹 배포를 완료했습니다.

## 실행 방법

- **온라인 배포 링크**: `https://kyudyessey.github.io/26-w06-apple/` (링크를 본인 계정 URL로 변경하세요)
- **로컬 실행**: 저장소를 Clone 한 후 `index.html` 파일을 브라우저로 열면 실행할 수 있습니다.

## 커스터마이징한 부분

- **목표 숫자 조건 변경**: 단순 '합이 10' 조건에서 더 높은 점수와 전략을 노릴 수 있는 **'10의 배수(10, 20, 30...)'** 조건으로 변경
- **타이머 조정**: 긴장감을 높이기 위해 제한시간을 **2분(120초)에서 1분(60초)**로 축소
- **드래그 UX 개선**: 드래그하는 도중 10을 지나쳐 20, 30의 배수까지 연속으로 선택할 수 있도록 mouseup 시점 최종 합산 판정 로직 적용
